\chapter{Formato de código para el módulo universidad-proyecto}

El código se presenta en fragmentos con resaltado de sintaxis para TypeScript. Conviene mantener el estilo siguiente:

\begin{itemize}[leftmargin=1.5cm]
  \item indentación de 2 o 4 espacios según archivo original (se respeta el estilo existente);
  \item nombres claros para tipos e interfaces (\texttt{MateriaInput}, \texttt{AsignacionResultado});
  \item comentarios mínimos en inglés o español según el contexto del archivo;
  \item pruebas y scripts comentados para reproducir comparativas.
\end{itemize}

Los fragmentos incluidos en las secciones extraen piezas relevantes del código real ubicado en \texttt{src/universidad-proyecto} y en \texttt{src/estructuras}.
